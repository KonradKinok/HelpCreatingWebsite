1.1 Git

      System kontroli wersji - program, który pozwala śledzić, modyfikować i zapisywać różne wersje plików projektu. Program ten działa na zasadzie punktów kontrolnych (commitów), w których przechowywane są różne stany plików.

      W repozytorium projektu (repozytorium bieżącego projektu, które jest pod kontrolą programu - w naszym przypadku programu git) przechowywane są różne commity (wersje) tego projektu. Obszar roboczy zawiera wszystkie pozostałe pliki projektu: style, znaczniki, ilustracje, skrypty itp.

      UWAGA! O czym należy pamiętać w przypadku commitów?

      • Commit zapisuje pełny stan przestrzeni roboczej projektu (pliki, foldery).
      • Jeśli w przestrzeni roboczej były zmiany, możemy je zapisać jako osobny commit.
      • W repozytorium pojawi się nowy commit z unikalnym identyfikatorem - numerem wersji.
      • Dodaj opis do commita, aby mieć pojęcie, co się zmieniło w tej wersji.
      • Wszystkie commity projektu są przechowywane w repozytorium.
      • Możesz cofnąć się do dowolnego commitu i zobaczyć, jak wyglądały pliki projektu.

      Git - to popularny systemem kontroli wersji, który jest obecnie używany w większości projektów. Dzięki git możesz tworzyć lokalne repozytoria na swoim komputerze.

      GitHub - to jedna z usług opartych na git, która pozwala na przechowywanie repozytoriów na serwerach w chmurze. GitHub umożliwia pracę ze zdalnymi repozytoriami, a tym samym dzielenie się kodem z zespołem - nad projektami może pracować jednocześnie 20-30 programistów lub więcej.

      2.1 Tworzymy repozytorium na GitHub

      • Publiczne repozytorium (Public) to repozytorium, którego kod źródłowy jest dostępny pod linkiem, czyli autor umożliwia innym korzystanie ze swojego kodu (nazywa się to open source software). Na GitHub możesz tworzyć nieograniczoną liczbę publicznych repozytoriów.
      • Prywatne repozytorium (Private) jest wykorzystywane do prywatnych projektów, dostęp do kodu w prywatnych repozytoriach jest ograniczony. Na GitHub można bezpłatnie utworzyć tylko 3 prywatne repozytoria. Tworzenie kolejnych prywatnych repozytoriów jest płatne.

      Na Github istnieje opcja .gitignore, która służy do ukrywania plików i folderów przed systemem kontroli wersji Git. Zazwyczaj pliki, których nie musimy kontrolować za pośrednictwem Git to ustawienia edytora VS Code, atrybuty folderów na komputerze, układy, pliki konfiguracyjne (zwłaszcza z hasłami), itp. Wszystko to można umieścić w .gitignore.

      3.2 Synchronizujemy GitHub Desktop i profil na github.com

      1. Aby skopiować repozytorium z Internetu na komputer, naciśnij przycisk Clone a Repository...
      2. Aby zalogować się na swoje konto GitHub i sklonować utworzone tam repozytorium naciśnij przycisk Sign in i naciśnij przycisk Continue with browser. Upewnij się, że masz otwarty profil GitHub w przeglądarce.
      3. Aby zsynchronizować profil na github.com z programem, który właśnie pobrałeś na komputer naciśnij przycisk Authorize desktop i poczekaj na przekierowanie do programu GitHub Desktop.
      4. Teraz na ekranie wyświetla się folder/repozytorium, które zostało utworzone w profilu na stronie github.com.

      3.3 Klonujemy repozytorium z profilu github.com na komputer

      1. Aby skopiować repozytorium z Internetu na komputer, naciśnij przycisk Clone a Repository...
      2. Wybierz interesujące Cię repozytorium ze zsynchronizowanego profilu GitHub kliknij na repozytorium i naciśnij Clone. Innym możliwym sposobem pobrania repozytorium jest wprowadzenie linku do repozytorium z Internetu. Aby to zrobić, należy: Nacisnąć przycisk URL Skopiować adres URL repozytorium z zakładki w Internecie i wstawić do pola wejściowego
      3. Za pierwszym razem sprawdź, gdzie dokładnie na komputerze znajduje się folder, do którego klonowane jest repozytorium. Aby to zrobić Naciśnij przycisk Choose i wybierz lub utwórz folder, w którym będą przechowywane wszystkie projekty z GitHub. Wybierz folder i naciśnij przycisk Select.
      4. Naciśnij Clone. Poczekaj i sprawdź, czy repozytorium pojawiło się w określonym folderze.

      3.4 Synchronizujemy GitHub i edytor VS Code

      1. Otwórz edytor kodu VS Code na swoim komputerze
      2. Naciśnij File i wybierz Open
      3. Otwórz folder z repozytorium, które sklonowałeś z Internetu
      4. Aby utworzyć nowy plik, w którym można pisać kod: umieść kursor na ikonie liścia i kliknij lewym przyciskiem myszy. W polu wejściowym wprowadź nazwę, na przykład index.html Naciśnij Enter. Pierwszy plik w tym projekcie został utworzony!
      5. Wprowadźmy zmiany w pliku index.html. Naciśnij klawisz Shift i cyfrę 1 Z listy rozwijanej wybierz ! (wykrzyknik) i Naciśnij Enter

      3.5 Tworzymy nowe repozytorium na podstawie poprzedniego

      1. Aby wszystkie materiały z istniejącego repozytorium znalazły się w nowym, należy utworzyć z niego szablon. W tym celu: otwórz repozytorium pierwszej pracy domowej na github, otwórz zakładkę Settings, zaznacz pole obok Template repository.
      2. Aby utworzyć nowe repozytorium, kliknij ikonę z + (plus), wybierz New repository z listy rozwijanej i wprowadź nazwę nowego repozytorium,
      3. Wybierz szablon, z którego należy wyciągnąć pliki. W tym celu: w bloku Repository template naciśnij przycisk No templates, z listy rozwijanej wybierz potrzebny szablon i naciśnij Create repository na dole strony.
      4. Aby utworzyć nowy plik, w którym można pisać kod: umieść kursor na ikonie liścia i kliknij lewym przyciskiem myszy. W polu wejściowym wprowadź nazwę, na przykład index.html Naciśnij Enter. Pierwszy plik w tym projekcie został utworzony!
      5. Wprowadźmy zmiany w pliku index.html. Naciśnij klawisz Shift i cyfrę 1 Z listy rozwijanej wybierz ! (wykrzyknik) i Naciśnij Enter
