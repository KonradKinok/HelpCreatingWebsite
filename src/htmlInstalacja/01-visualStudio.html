1.1 Visual Studio

      Visual Studio Code (VS Code) to potężny edytor kodu, który działa na komputerze i jest dostępny dla systemów Windows, macOS i Linux. Obsługuje różne języki programowania (JavaScript, TypeScript i Node.js) i ma bogaty ekosystem rozszerzeń dla innych języków (C++, Java, Python itp.) i runtimów.

      1.2 Pobranie

      linku https://code.visualstudio.com/, aby odwiedzić stronę VS Code. Kliknij przycisk "Download for Windows" (lub odpowiedni dla Twojego systemu operacyjnego), aby pobrać instalator.

      2.1 Interfejs VSCode

      Główne elementy interfejsu VS Code

      Zacznijmy od panelu kontrolnego po lewej stronie, który zawiera 5 zakładek.

      • Explorer — pozwala przeglądać i zarządzać plikami oraz folderami w projekcie. Możesz otwierać, tworzyć, usuwać i przenosić pliki oraz foldery.
      • Search — umożliwia wyszukiwanie tekstu w plikach projektu. Możesz również używać wyrażeń regularnych i filtrować wyniki według typów plików.
      • Debugowanie — umożliwia debugowanie kodu w czasie rzeczywistym, ustawianie punktów przerwania i analizowanie zmiennych.
      • Rozszerzenia — pozwala instalować dodatkowe funkcje i narzędzia do VS Code, takie jak obsługa nowych języków programowania, motywy kolorystyczne i integracje z systemami kontroli wersji.

      3.1 Ustawienia

      1. Aby otworzyć panel ustawień
        • kliknij Ustawienia (ikona koła zębatego) w lewym dolnym rogu okna VS Code
        • wybierz „Ustawienia" lub "Settings" z menu rozwijanego lub użyj skrótu klawiaturowego Ctrl + , (Windows/Linux) lub Cmd + , (macOS).

          Pomocne! Użyj funkcji wyszukiwania słów kluczowych, aby dokonać określonych ustawień w VS Code.

      2. Aby wyszukać ustawienia czcionki w edytorze, wpisz czcionkę w pasku wyszukiwania.
        • W sekcji wyników można zobaczyć wszystkie dostępne ustawienia związane z czcionką
        • Aby zmienić rozmiar czcionki, kliknij pole obok „Editor: Font Size" i wprowadź nową wartość (np. 16).
      3. Aby dostosować motyw
        • kliknij Temat ikon plików. W rozwijanym menu wybierz motyw, który Ci odpowiada, używając klawiszy góra/dół - zmieni się kolor ikon plików i folderów;
        • naciśnij Enter, aby potwierdzić swój wybór.
      4. Gdy w edytorze pojawi się więcej tekstu, możesz zauważyć, że niektóre linie są poza zasięgiem wzroku. Może to być niewygodne - spójrz na zieloną strzałkę. Aby dostosować podziały linii
      5. Aby włączyć automatyczne zapisywanie kodu
        • w linii wprowadzania danych wpisz autozapis
        • otwórz menu pod ustawieniem Auto Save
        • z listy rozwijanej wybierz onFocusChange
      6. Dodajmy rozszerzenie HTML CSS Support, które pomoże przyspieszyć tworzenie układu i zapobiegnie błędom. Aby to zrobić:
        • W pasku wyszukiwania wpisz html css support
        • Kliknij na wymagane rozszerzenie z listy
        • Kliknij przycisk Instaluj.
        • Rozszerzenie jest instalowane raz. Po tym czasie będzie ono aktywne we wszystkich przyszłych projektach.
      7. Dodajmy rozszerzenie Path Intellisense, które pomoże przyspieszyć układ i zapobiec błędom. Aby to zrobić:
        • W pasku wyszukiwania wpisz path intellisense
        • Kliknij na wymagane rozszerzenie z listy
        • Kliknij przycisk Instaluj.
        • Rozszerzenie jest instalowane raz. Po tym czasie będzie ono aktywne we wszystkich przyszłych projektach.
      8. Aby zainstalować rozszerzenie umożliwiające formatowanie kodu w jednolitym stylu według standardów, wyszukaj Prettier - Code formatter i zainstaluj je. Po zainstalowaniu rozszerzenia możesz ustawić je jako domyślny formatator kodu, aby automatycznie formatować kod przy zapisie pliku. Aby to zrobić:
        • W pasku wyszukiwania wpisz prettier
        • Kliknij na wymagane rozszerzenie z listy
        • Kliknij przycisk Instaluj.
        • Po zainstalowaniu rozszerzenia, otwórz ustawienia (Ctrl + ,) i wyszukaj "default formatter". Wybierz "Prettier - Code formatter" jako domyślny formatator kodu.
      9. Aby zainstalować rozszerzenie, które umożliwia automatyczne formatowanie za pomocą programu Prettier podczas zapisywania plików
        • w pasku wyszukiwania wpisz nazwę rozszerzenia Formatting Toggle;
        • kliknij pierwsze rozszerzenie z listy;
        • Kliknij przycisk Instaluj.
        • Po zainstalowaniu rozszerzenia, otwórz ustawienia (Ctrl + ,) i wyszukaj "default formatter". Wybierz "Prettier - Code formatter" jako domyślny formatator kodu.
      10. W głównym katalogu projektu utwórz plik konfiguracyjny Prettier o nazwie .prettierrc.json i dodaj do niego następujące ustawienia: 
                        {
                  "printWidth": 80,
                  "tabWidth": 2,
                  "useTabs": false,
                  "semi": true,
                  "singleQuote": true,
                  "trailingComma": "es5",
                  "bracketSpacing": true,
                  "jsxBracketSameLine": false,
                  "arrowParens": "avoid",
                  "proseWrap": "always"
                }

      14. Przydatne! Aby zobaczyć wszystkie rozszerzenia na ten sam temat, na przykład rozszerzenia zmieniające motywy i ikony. W pasku wyszukiwania wpisz zapytanie, na przykład @category:themes, i wybierz te, które Ci się podobają. Wybór jest bardzo duży, więc najpierw zwróć uwagę na najpopularniejsze rozszerzenia - czyli takie, które mają największą liczbę pobrań. Możesz również szukać rozszerzeń innych tematów.
      15. Dodaj rozszerzenie colorize. Czynności tak jak wyżej. Rozszerzenie colorize natychmiast wizualizuje kolory css w twoim projekcie. To rozszerzenie również wyszukuje kolory i tworzy tło (używając odpowiedniego koloru) dla każdego stylu koloru w plikach CSS, SCSS i HTML. Kolory są wyświetlane w formacie HEX, RGB, HSL i nazwanych kolorach.
      16. Dodaj rozszerzenie Gremlins tracker for Visual Studio Code. Trailer Gremlins dla rozszerzenia Visual Studio Code pokazuje potencjalnie problematyczne znaki - niewidoczne lub niebezpieczne znaki, takie jak ukraińskie i angielskie "c", które wyglądają prawie identycznie, nieprawidłowy typ myślnika (krótki, długi, myślnik), cytaty typograficzne itp.
      17. Dodaj rozszerzenie Live Server. Serwer internetowy dla deweloperów działa bezpośrednio na komputerze: symuluje prawdziwy serwer WWW, zapewnia dodatkową funkcjonalność, na przykład automatyczne przeładowanie karty przeglądarki po wprowadzeniu zmian w kodzie projektu. Na pasku stanu pojawi się ikona Go Live.
