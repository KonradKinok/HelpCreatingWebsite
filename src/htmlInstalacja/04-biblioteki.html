      1.3 Embedded Sass Host

      Instalowane w devDependencies do scss

                  npm i -D sass-embedded

      Embedded Sass Host Pakiet ten stanowi alternatywę dla pakietu `sass`. Obsługuje to samo API języka JavaScript co `sass` i jest utrzymywany przez ten sam zespół; jednak o ile pakiet `sass` jest napisany w całości w języku JavaScript, o tyle `sass-embedded` stanowi jego javascriptową otoczkę dla natywnego pliku wykonywalnego języka Dart. Oznacza to, że `sass-embedded` będzie zazwyczaj działać znacznie szybciej - zwłaszcza w przypadku kompilacji dużych projektów Sass - ale można go zainstalować tylko na platformach obsługiwanych przez język Dart: Windows, macOS i Linux. Mimo że są to odrębne pakiety, zarówno `sass`, jak i `sass-embedded` uznaje się za "Dart Sass", ponieważ opierają się na tej samej implementacji. Od momentu wydania pierwszej stabilnej wersji pakietu `sass-embedded` oba pakiety są publikowane jednocześnie i mają ten sam numer wersji.

      1.4 react-tooltip

                  npm i react-tooltip

      react-tooltip to biblioteka działająca po stronie klienta. Wykorzystuje ona hooki, obserwatory DOM, zdarzenia przeglądarki oraz pomiary układu strony, dlatego sam komponent tooltipa musi działać w obrębie komponentu klienta. Rozwiązanie to sprawdza się w frameworkach takich jak Next.js z obsługą Server Components, jednak komponent Tooltip należy renderować wewnątrz komponentu klienta, a atrybuty lub selektory tooltipa przypisywać do elementów renderowanych w tym samym obszarze klienta. W przypadku korzystania z React Server Components obowiązuje prosta zasada praktyczna: komponenty serwera mogą renderować znacznik elementu kotwicy (anchor), komponenty klienta powinny renderować i obsługiwać react-tooltip. W Next.js typową praktyką jest eksportowanie tooltipa z niewielkiego pliku opakowującego (wrapper), oznaczonego dyrektywą 'use client'.

      https://react-tooltip.com/docs/getting-started

      1.6 Lucide React

                  npm i lucide-react
          
                  npm install --save-dev @types/lodash

      Lucide udostępnia bibliotekę komponentów React do wykorzystania ikon w aplikacjach. Każda ikona dostępna jest jako samodzielny komponent renderujący zoptymalizowany kod SVG typu inline. Kluczowe cechy: Łatwość użycia - importuj ikony i korzystaj z nich bezpośrednio w JSX. Możliwość dostosowania - zmieniaj rozmiar, kolor, grubość linii i inne właściwości za pomocą propsów. Obsługa tree-shakingu - w finalnym pakiecie aplikacji uwzględniane są tylko te ikony, które faktycznie zaimportowano. Obsługa TypeScript - w pełni typowane komponenty zapewniające większy komfort pracy programisty.

      https://lucide.dev/guide/react/

      1.9 Axios

                  npm i axios

      Wysyłaj żądania XMLHttpRequest z poziomu przeglądarki. Wysyłaj żądania HTTP z poziomu Node.js. Korzystaj z API Promise do asynchronicznej obsługi żądań. Przechwytuj żądania i odpowiedzi, aby dodać własną logikę lub przekształcić dane. Przekształcaj dane żądań i odpowiedzi. Anuluj żądania za pomocą wbudowanych mechanizmów anulowania. Serializuj i parsuj dane w formacie JSON. Serializuj obiekty danych do formatów multipart/form-data lub application/x-www-form-urlencoded. Dodaj zabezpieczenia po stronie klienta przed atakami typu Cross-Site Request Forgery (CSRF).

      https://axios.rest/
