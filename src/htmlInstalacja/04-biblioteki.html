      1.2 React Router

                  npm i react-router

      React Router to router dla Reacta, który oferuje różne podejścia do implementacji. Możesz korzystać z niego w pełnym zakresie - jak z frameworka Reacta - lub w sposób minimalistyczny, jako z biblioteki wkomponowanej we własną architekturę.

      1.3 Embedded Sass Host

      Instalowane w devDependencies do scss

                  npm i -D sass-embedded

      Embedded Sass Host Pakiet ten stanowi alternatywę dla pakietu `sass`. Obsługuje to samo API języka JavaScript co `sass` i jest utrzymywany przez ten sam zespół; jednak o ile pakiet `sass` jest napisany w całości w języku JavaScript, o tyle `sass-embedded` stanowi jego javascriptową otoczkę dla natywnego pliku wykonywalnego języka Dart. Oznacza to, że `sass-embedded` będzie zazwyczaj działać znacznie szybciej - zwłaszcza w przypadku kompilacji dużych projektów Sass - ale można go zainstalować tylko na platformach obsługiwanych przez język Dart: Windows, macOS i Linux. Mimo że są to odrębne pakiety, zarówno `sass`, jak i `sass-embedded` uznaje się za "Dart Sass", ponieważ opierają się na tej samej implementacji. Od momentu wydania pierwszej stabilnej wersji pakietu `sass-embedded` oba pakiety są publikowane jednocześnie i mają ten sam numer wersji.
