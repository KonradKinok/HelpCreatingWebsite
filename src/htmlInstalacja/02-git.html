1.1 Git

      System kontroli wersji - program, który pozwala śledzić, modyfikować i zapisywać różne wersje plików projektu. Program ten działa na zasadzie punktów kontrolnych (commitów), w których przechowywane są różne stany plików.

      W repozytorium projektu (repozytorium bieżącego projektu, które jest pod kontrolą programu - w naszym przypadku programu git) przechowywane są różne commity (wersje) tego projektu. Obszar roboczy zawiera wszystkie pozostałe pliki projektu: style, znaczniki, ilustracje, skrypty itp.

      UWAGA! O czym należy pamiętać w przypadku commitów?

      • Commit zapisuje pełny stan przestrzeni roboczej projektu (pliki, foldery).
      • Jeśli w przestrzeni roboczej były zmiany, możemy je zapisać jako osobny commit.
      • W repozytorium pojawi się nowy commit z unikalnym identyfikatorem - numerem wersji.
      • Dodaj opis do commita, aby mieć pojęcie, co się zmieniło w tej wersji.
      • Wszystkie commity projektu są przechowywane w repozytorium.
      • Możesz cofnąć się do dowolnego commitu i zobaczyć, jak wyglądały pliki projektu.

      Git - to popularny systemem kontroli wersji, który jest obecnie używany w większości projektów. Dzięki git możesz tworzyć lokalne repozytoria na swoim komputerze.

      GitHub - to jedna z usług opartych na git, która pozwala na przechowywanie repozytoriów na serwerach w chmurze. GitHub umożliwia pracę ze zdalnymi repozytoriami, a tym samym dzielenie się kodem z zespołem - nad projektami może pracować jednocześnie 20-30 programistów lub więcej.

      2.1 Tworzymy repozytorium na GitHub

      1. Otwórz narzędzia programistyczne i przejdź do karty „Network".
      2. Wybierz filtr „CSS", aby były wyświetlane tylko pliki stylów.
      3. Kliknij plik z Google Fonts.
      4. Wybierz kartę „Preview", która wyświetli zawartość pliku.
